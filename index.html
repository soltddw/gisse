1. Introducción

El presente trabajo recopila las reflexiones académicas obtenidas tras la observación guiada del material técnico audiovisual. El propósito fundamental es argumentar las etapas clave para la maquetación y puesta en marcha de un sitio web funcional, adaptado a la estética naranja y estructurado para su distribución en internet.

2. Conceptos Fundamentales

01

Maquetación HTML

Construcción de la infraestructura del sitio usando componentes semánticos organizados.

02

Estilizado CSS

Diseño de colorimetría, cajas, espacios y respuestas dinámicas ante la interacción.

03

Repositorio Git

Almacén centralizado de archivos para el seguimiento de versiones del proyecto.

04

Publicación Web

Proceso que vincula el código fuente con un dominio accesible mediante protocolo HTTPS.

3. Cuestionario Resuelto

01

¿Cuál es el tema principal del video? Explica de qué trata.

Trata sobre las metodologías necesarias para convertir código local en un sitio web público mediante el uso de herramientas de control de código y servicios de alojamiento automatizados.

02

¿Qué problema o necesidad tecnológica se aborda?

Se aborda la dificultad de hacer públicos los proyectos desarrollados en la computadora de estudio, ofreciendo una alternativa práctica, segura y gratuita sin lidiar con servidores complejos.

03

¿Cuáles son los cinco conceptos más importantes? Define cada uno.

• Semántica: Uso correcto de las etiquetas HTML para definir partes del documento.
• CSS Flexbox: Modelo de maquetación para alinear elementos en filas o columnas.
• Hosting Estático: Alojamiento enfocado en archivos de cliente (HTML, CSS, JS).
• Deploy: Acción de compilar y desplegar la versión final a los servidores.
• Responsividad: Capacidad del diseño de reajustarse automáticamente en dispositivos móviles.

04

¿Qué herramientas, programas o tecnologías se mencionan y para qué sirven?

Se utiliza **VS Code** como entorno de edición, **GitHub** como bóveda pública para almacenar repositorios y plataformas de despliegue como **Render** o **Netlify** para transmitir los archivos a la web.

05

¿Qué procedimientos o pasos se explican? Preséntalos en orden.

1. Redacción y prueba de los archivos `index.html` y `estilos.css`.
2. Inicialización de un nuevo repositorio público en la plataforma GitHub.
3. Carga directa de los archivos mediante la interfaz de subida (*Uploading an existing file*).
4. Guardado formal mediante un *Commit* en la rama principal.
5. Vinculación del repositorio en Render (*Static Site*) para la obtención de la dirección URL.

06

¿Qué ejemplos prácticos aparecen? Explica uno detalladamente.

Muestra cómo probar enlaces en vivo: una vez generado el enlace en Render, se realiza la apertura en una pestaña de incógnito para constatar que el contenido es público y no depende de credenciales locales.

07

¿Qué conocimientos previos son necesarios para comprender lo explicado?

Operaciones básicas del sistema operativo, estructuración de carpetas, reglas gramaticales básicas de marcado web (etiquetas) y manejo de interfaces en navegador.

08

¿Qué ventajas o beneficios ofrece la tecnología o procedimiento?

Garantiza un aprendizaje dinámico, permite construir un portafolio web personal desde etapas escolares y agiliza la entrega de tareas técnicas sin necesidad de almacenamiento físico.

09

¿Qué dificultades, errores o precauciones deben considerarse?

Se debe cuidar la escritura de las rutas de archivos (evitar diferencias entre minúsculas y mayúsculas) y asegurar que el repositorio de GitHub no se guarde como privado.

10

¿Cómo aplicarías lo aprendido en un proyecto informático real?

Implementando este proceso en la creación de páginas promocionales para emprendimientos, sitios de información escolar o paneles interactivos para clientes.

11

¿Qué parte del video consideras más importante y por qué?

La sección dedicada al orden del código y la subida limpia a GitHub, puesto que un proyecto bien estructurado evita fallos al conectarse con el servidor de hosting.

12

¿Qué conocimientos nuevos adquiriste y cómo los explicarías a otra persona?

Adquirí destreza en el flujo de publicación en servidores. Lo explicaría comparándolo con mandar una carta: redactas el mensaje (código), lo metes en un buzón de envíos (GitHub) y el correo (Render) lo lleva a la dirección pública para que todos lo puedan leer.

4. Aplicación Práctica

Para la ejecución práctica de esta tarea se maquetó este portal web con HTML5, aplicando estilos personalizados en tonos naranja cálido con reglas CSS3 adaptables a móviles. Toda la estructura fue sincronizada con un repositorio en GitHub y desplegada públicamente mediante los servicios de Render.

5. Conclusión Personal

El ejercicio permitió afianzar destrezas esenciales sobre el flujo de trabajo moderno en el desarrollo web. La combinación entre código estructurado, diseño de interfaz amigable y publicación en tiempo real constituye una base fundamental para el avance en la especialidad de informática.
